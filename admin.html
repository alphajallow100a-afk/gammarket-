Help & Docs

1. Approve Merchant: Go to Merchants → Approve.
2. Release Escrow: Go to Escrow → Release. Pays 100% to merchant.
3. Payout: Go to Payouts → Enter amount → Send.
4. Delete Product: Marketplace → Delete.
5. Change Order Status: Orders → Mark Shipped / Completed.
6. Auto-Deduct: Subscription D300 first 2 months, then D1000 auto-deducts from merchant wallet when due. Withdrawal 1% auto-deducts on every withdrawal. Tap "Run Auto-Deduct Now" to force it.
7. Confirm Deposit (NEW): Go to Deposits → Check your Wave app for money to +220877859091 → Match Tx ID → Tap ✅ Approve. Wallet increases only after you approve. Min D400.
8. Confirm Withdrawal (NEW): Go to Withdrawals → Send (Amount - 1% fee) via Wave to user's phone → Tap ✅ Paid via Wave. Wallet deducted on Paid. Example: Request D400 → Send D396. Min D400.
